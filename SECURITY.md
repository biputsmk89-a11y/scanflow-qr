# Security Policy — ScanFlow QR

## 1. Supported Versions
We provide security patches for the following versions:

| Version | Supported |
| :--- | :--- |
| `1.0.x` | ✅ Yes |
| `< 1.0.0` | ❌ No |

---

## 2. Reporting a Vulnerability
We take the security of our users and untrusted payload processing seriously.

If you discover a security vulnerability (such as a parsing exploit, URL bypass, or biometric bypass):
1. **DO NOT** open a public GitHub issue.
2. Email your findings privately to **security@scanflow.app** (or the repository maintainer).
3. Include detailed steps to reproduce, sample payloads, device OS version, and severity assessment.

### Response Timeline
- **Initial Response**: Within 24–48 hours.
- **Triage & Patch**: Within 5–7 business days.
- **Public Disclosure**: Coordinated after the fix is published to Google Play Store.
